# MLProject

Machine learning experiments in Python: SVM and logistic regression, in Jupyter notebooks.

## Contents

- `ML_Project_SVM.ipynb` — Support Vector Machine experiments
- `ML_Project_Code_Logistic_Regression_.ipynb` — Logistic regression experiments
- `linearregressiontitanic.py` — Linear regression on the Titanic dataset

## How to run

Open any notebook in Jupyter / Google Colab and run cells top to bottom:

```bash
pip install jupyter scikit-learn pandas numpy
jupyter notebook
```
